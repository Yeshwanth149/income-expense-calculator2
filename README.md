# 💰 Monthly Income & Expense Calculator

A simple and user-friendly web application for calculating and managing **monthly income and expenses**. This mini project was developed using **HTML, CSS, and JavaScript**.
 
## 📌 Project Overview

The **Monthly Income & Expense Calculator** helps users keep track of their income and expenses in one place.

Users can add different transactions, select whether they are income or expenses, and the application automatically calculates:

- 💵 Total Income
- 💸 Total Expenses
- 💰 Remaining Balance
- 📋 Transaction History

## ✨ Features

- ➕ Add income transactions
- ➖ Add expense transactions
- 🧮 Automatically calculate total income
- 🧮 Automatically calculate total expenses
- 💰 Calculate remaining balance
- 📋 Display transaction history
- 🗑️ Delete transactions
- 📱 Responsive design
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the application |
| CSS3 | Styling and responsive design |
| JavaScript | Application logic and calculations |
